# UI Design Details

## 컬러프리셋 관리

별도의 팝업창에서 컬러 프리셋을 추가,삭제,수정 관리할 수 있는 기능. RGB 코드를 입력하거나, 컬리픽커에서 선택하여 색이름을 지정한 후 저장할 수 있다. 

## 실팔찌 시뮬레이션 미리보기 

### Zoom 기능

실팔찌 결과 미리보기를 zoom in/out 할 수 있는 기능

### 실의 촘촘하기 조절 기능

슬라이더 형태의 촘촘하기를 조절할 수 있는 기능

## 갤러리 기능

Firebase DB에 저장된 쿠미히모 패턴의 시각화를 갤러리 형태로 전시할 수 있는 별도의 페이지. 클릭시 상세 화면으로 연결된다.
