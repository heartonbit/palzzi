# 상세 설계 

## 1단계: MVP용 쿠미히모 스펙 고도화 (줄 수 변경 지원)

유저가 4줄, 6줄, 8줄, 16줄 등 짝수 가닥의 줄 수를 선택하면, 앱은 이에 맞는 디스크 슬롯 초기 배치와 결과물 시뮬레이션을 자동으로 계산합니다.

기본 제공 라인업: 4줄, 6줄, 8줄, 12줄, 16줄 (쿠미히모는 대칭 구조상 주로 짝수/4의 배수 단위를 사용합니다.)

작동 방식: 유저가 줄 수를 선택하면 원형 디스크 위에 해당 가닥수만큼 실이 균등하게 배치되고, 각 실의 색상을 변경할 수 있는 슬롯이 활성화됩니다.

## 2단계: 화면 레이아웃 및 UI 구상 (Functional UI Wireframe)

사용자가 접속했을 때 마주할 화면의 배치(레이아웃) 설계입니다. 태블릿이나 PC, 모바일 화면을 모두 고려하여 크게 3개의 영역(패널)으로 분할합니다.

```
+-----------------------------------------------------------------------+
|  [상단 바] 프로젝트 이름 (Palzzi) / 내보내기 버튼 (PNG, SVG, JSON)       |
+-----------------------------------------------------------------------+
|                                                                       |
|  [좌측 패널: 설정 & 제어]             [중앙 패널: 가상 워크스페이스]        |
|                                                                       |
|  1. 줄 수 선택 (Dropdown)             +-----------------------+       |
|     [ 4줄 | 6줄 | 8줄★ | 16줄 ]        |                       |       |
|                                       |     (32슬롯 원형 디스크) |       |
|  2. 실 색상 커스텀 (Palette)          |          [실]         |       |
|     * 선택된 실: #FF5733              |       [실]   [실]     |       |
|     * 색상 변경 버튼들                 |          [실]         |       |
|                                       +-----------------------+       |
|  3. 저장 및 불러오기                   | [하단 패널: 완성본 미리보기]    |
|     [ 로컬 저장 ] [ 공유 URL 생성 ]     | --------------------- |       |
|                                       | (짜여진 쿠미히모 끈 이미지)    |
|                                       | ===================== |       |
+-----------------------------------------------------------------------+
```

각 영역별 상세 기능 (Functional Spec)
좌측 제어 패널 (Control Panel):

줄 수 변경 조작: 드롭다운이나 라디오 버튼을 통해 줄 수를 변경하면 중앙 디스크의 실 개수가 즉시 갱신됩니다.

색상 피커 (Color Picker): 디스크 위의 실을 클릭한 후, 원하는 색상을 선택해 바꿀 수 있는 팔레트입니다. 등록된 프리셋 컬러 중에 선택하는 것을 디폴트로 하고 추가로 프리셋에 없는 색상은 컬러 픽커를 통해 선택할 수 있도록 합니다.

중앙 디스크 패널 (2D Disk View):

실제 쿠미히모 디스크(32개 슬롯)를 상징하는 2D 원형 그래픽이 배치됩니다.

선택한 줄 수에 따라 실들이 디스크 자리에 꽂혀 있는 모습이 선과 점으로 표현됩니다.

하단 결과물 패널 (Finished Preview View):

이 앱의 핵심 부분입니다. 사용자가 디스크 위에서 색상을 바꾸면, 그 조합대로 무한히 짜여 내려갔을 때 완성될 '원통형 끈의 표면 패턴'이 2D 평면 그리드로 계산되어 실시간으로 업데이트됩니다.
쿠미히모 원형 끈을 평면(2D)으로 펼쳐서 각 실의 꼬임과 패턴을 한눈에 볼 수 있는 뷰도 함께 제공한다. 

## 3단계: 쿠미히모 회전 데이터 구조 설계 (Technical Data Modeling)

컴퓨터가 사용자의 색상 선택을 받아 최종 팔찌 이미지로 표현하기 위한 JSON 데이터 구조 설계입니다. 사용자가 줄 수를 4줄, 6줄 등으로 바꿀 때마다 totalThreads와 initialSlots 배열의 길이가 유연하게 바뀝니다.

Palzzi 쿠미히모 MVP 표준 JSON 스키마

```
JSON
{
  "projectId": "palzzi-k-001",
  "projectName": "나의 첫 쿠미히모 끈",
  "craftType": "KUMIHIMO_ROUND",
  "meta": {
    "totalThreads": 6, 
    "diskSlots": 32,
    "patternName": "6-Strand Basic Spiral"
  },
  "colorPalette": {
    "colorA": "#FF5733",
    "colorB": "#3366FF",
    "colorC": "#FFFFFF"
  },
  "initialSlots": [
    {"slotNumber": 32, "threadColor": "#FF5733"},
    {"slotNumber": 1, "threadColor": "#FF5733"},
    {"slotNumber": 10, "threadColor": "#3366FF"},
    {"slotNumber": 11, "threadColor": "#3366FF"},
    {"slotNumber": 21, "threadColor": "#FFFFFF"},
    {"slotNumber": 22, "threadColor": "#FFFFFF"}
  ],
  "weavingRules": {
    "sequenceType": "STANDARD_ROUND_COUNTER_CLOCKWISE",
    "description": "우측 상단 실을 우측 하단으로, 좌측 하단 실을 좌측 상단으로 이동하는 교차 규칙"
  }
}
```

엔지니어링 핵심 로직 (Algorithm Note)
패턴 역산 매트릭스: 쿠미히모는 실이 빙글빙글 돌면서 꼬이기 때문에, 원형 디스크 상의 실 순서가 완성본 코드(Cord) 표면의 나선형 무늬로 규칙적으로 배열됩니다.

개발 시 initialSlots에 담긴 색상 순서대로 패턴 배열(2D 행렬)을 밀어내며 그려주는 회전 맵핑 함수(Rotation Mapping Function)를 가볍게 구현하여 하단 프리뷰 캔버스에 뿌려주게 됩니다.
